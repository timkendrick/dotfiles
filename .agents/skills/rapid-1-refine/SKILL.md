# RAPID Workflow Step 1: Refine

Your goal is to collaboratively refine the task description, fleshing out any areas lacking detail or containing uncertainty into robust, actionable requirements.

Ask a long series of increasingly specific questions in order to remove all ambiguity from the requirements.

The output of this session will be a `.agents/plans/*.requirements.md` markdown file that contains the refined requirements document.

At this stage we're not concerned with actual implementation details, just refining the task.
