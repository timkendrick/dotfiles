# JFDI Workflow

The JFDI workflow is a simple interactive workflow for enacting requirements that are already well-specified and do not warrant extended planning. It consists of 3 steps:

1. Summarize – present the user with a summary of any actions you are about to take. If the user intent is clear from the requirements, proceed to step 2. If the requirements are genuinely ambiguous, await user confirmation before proceeding to step 2.
2. Act – implement the summarized actions.
3. Summarize – present the user with a summary of the actions taken and any necessary deviations that arose while enacting them.
